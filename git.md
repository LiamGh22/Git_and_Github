What is Git?
the world's most popular version control system
and what is a version control system:
a version control is a software that tracks and manages changes to files over time.
version control systems generally allow uses to revisit earlier versions of the files, compare changes between versions, undo changes and a whole lot more.
Git is just one VCS(version controll system)

what exactly does Git for us?
* Git helps us ...
* track changes across multiple files
* compare versions of a project
* time travel => back to older version 
* revert to a previous version
* collabrate and share changes 
* combine changes(it is very cool!)

The Difference between Git and Github:
Git:
 is the version controll system that runs locally on your machine. you don't need the internet to use it or you dont need to register for an account. you can use it without ever touching github.

Github:
 is a service that hosts Git repositories in the cloud and makes it easier to collabrate with other people.
 you do need to sign up fot an account to use it. it is an online place to shre work that is done using Git.
